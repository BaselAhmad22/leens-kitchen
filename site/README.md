# Leen's Middle East Kitchen

Premium marketing site for **Leen's** (TTDI, Kuala Lumpur).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content source

Site data and images live in the sibling folder:

- `../leens-content/site-data.json`
- `../leens-content/images/`

Edit them via the admin app:

```bash
cd ../leens-admin
npm run dev
```

Admin: [http://localhost:3001](http://localhost:3001) (password `leenadmin`).

## Pages

- `/` Home
- `/menu` Menu
- `/about` Story
- `/reserve` Reservations
